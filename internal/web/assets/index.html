Fallback routing
Ordered virtual routes try each target in turn. This timeout bounds how long a stalled target may delay before the next target is tried. Cooldown skips temporarily failing targets to avoid repeated retries.
Be careful setting this too low — it must be high enough for the provider to process the request and start responding. We recommend keeping it at least 60 seconds.
When a target fails with a cooldown-triggering failure, it is skipped for this many seconds. 0 disables cooldown. Maximum 86400 (24 hours). Default: 300 (5 minutes).
